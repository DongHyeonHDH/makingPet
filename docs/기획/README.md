## 핵심 원칙 (TL;DR)
1. **컨트랙트 먼저, 구현은 나중에.** API·프로토콜 명세가 확정된 뒤에 코드를 쓴다.
2. **서버가 권위를 가진다.** 뽑기 결과, 미니게임 결과, 재화 증감, 거래 체결은 모두 서버가 결정한다. 클라이언트는 보여주기만 한다.
3. **재화는 원장(ledger)으로만 움직인다.** 잔액을 직접 고치지 않고, 모든 증감을 거래 기록으로 남긴다.
4. **다른 도메인의 엔티티를 직접 import하지 않는다.** ID만 보관하고 상대 도메인의 service를 호출한다.
5. **유료 재화는 없다.** 모든 재화는 플레이(출석·미니게임·판매)로만 얻는다.
