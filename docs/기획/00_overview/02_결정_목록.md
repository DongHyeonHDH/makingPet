# 02. 결정 목록 (Decision Log)

> 번호가 붙은 결정을 모은 **단일 기록**이다. 결정이 궁금하면 여기서 번호와 요약을 보고, 자세한 내용은 "기준 문서"에서 본다.
> 문서끼리 충돌하면 이 표 → 기준 문서 → 나머지 문서 순으로 따른다.
> 2026-11-18 작성. `04_api/README.md`의 "확정된 결정"(D-1~D-12)을 옮겨 오고 D-13 이후를 더했다.

## 규칙
- 새 결정은 다음 번호를 붙여 **맨 아래에 추가** → 기준 문서 반영 → 영향 문서 반영 순으로 처리한다.
- 결정을 뒤집거나 바꾸면 행을 지우지 않는다. 상태를 `대체됨 (→ D-n)` 또는 `일부 대체`로 바꾸고 새 행을 추가한다.
- 상위 결정을 다듬는 세부 결정은 소수점 번호(D-14.1)를 쓴다. 다른 문서에는 상위 번호(D-14)로만 적혀 있어도 된다.
