> ⚠️ 2026-11-16 초안. 새 용어는 이 문서에 먼저 추가하고 다른 문서에서 링크한다.

## A. 도메인 용어
| 용어 | 한 줄 정의 | 예시 / 관련 문서 |
|---|---|---|
| 펫 종 (PetSpecies) | 운영자가 정의한 펫 원형. 이름·희귀도·계열·단계·기본 이미지·기본 움직임을 가진다. 16종 | 오리, 화난 오리, 들고양이 |
| 계열 (Line) | 같은 기본종에서 진화로 이어지는 종 4개의 묶음. 오리·강아지·고양이·공룡 4계열 (D-13) | 오리 → 화난 오리 → 폭풍 오리 → 천둥 오리 |
| 기본종 / 진화형 | 1단계(COMMON) 종 / 2~4단계(RARE~LEGENDARY) 종. 뽑기는 기본종만, 진화형은 진화로만 | 02_게임_시스템_규칙 §1-1, §8 |
| 보유 펫 (UserPet) | 유저가 가진 펫 1마리. 같은 종을 여러 마리 가질 수 있다 | 03_erd `user_pets` |
| 희귀도 (Rarity) | 펫·아이템의 등급. `COMMON < RARE < EPIC < LEGENDARY`. 펫은 진화 단계와 1:1 (1단계 = COMMON … 4단계 = LEGENDARY) | 02_게임_시스템_규칙 §1, §8 |
| 대표 펫 | 마이 홈·프로필에 노출되는 보유 펫 1마리 | |
| 기분 (Mood) | 상호작용에 따라 오르고 시간에 따라 내려가는 0~100 수치 | 02_게임_시스템_규칙 §2 |
| 친밀도 (Affection) | 누적 상호작용으로 오르는 수치. 단계가 오르면 움직임이 해금된다 | |
| 상호작용 (Interaction) | 쓰다듬기·놀아주기·간식 주기 같은 펫 행동 | |
| 움직임 (Motion) | 펫이 마이 홈에서 재생하는 애니메이션. 장착 슬롯 중 하나 | 기본 움직임 / 해금 움직임 |
| 장착 슬롯 (Slot) | `TOP`(상의), `BOTTOM`(하의), `ACCESSORY`(악세서리), `MOTION`(움직임) | |
| 마이 홈 (My Home) | 대표 펫과 방 꾸미기가 보이는 개인 공간 겸 개인 페이지 | 05_ia_userflow |
| 방 테마 (Theme) | 마이 홈의 벽지·바닥 묶음 | |
| 가구 (Furniture) | 마이 홈에 배치하는 아이템 | 폭신한 러그 |
| 뽑기 풀 (Gacha Pool) | 뽑기 1종류와 그 확률표. 기간 한정 풀을 둘 수 있다 | |
| 천장 (Pity) | N회 연속으로 고등급이 나오지 않으면 다음 뽑기에서 보장하는 장치 | |
| 중복 보상 | 이미 가진 펫이 나왔을 때 주는 코인 | |
| 코인 (Coin) | 유일한 재화. 무료 획득만 가능 | |
| 원장 (Ledger) | 코인 증감을 한 줄씩 남기는 append-only 기록 | `coin_transactions` |
| 출석 | 하루 1회 보상. 연속 출석일에 따라 보상이 커진다 | |
| 가위바위보 | 하루 1회 참여하는 미니게임 | |
| 빠칭코 (슬롯) | 하루 N회 참여하는 슬롯 미니게임. 참가비와 배당이 있다 | |
| 상점 (Shop) | 운영자가 고정가로 판매하는 곳. 재고 무한 | |
| 경매장 (Auction) | 유저끼리 아이템을 사고파는 곳 | |
| 매물 (Listing) | 경매장에 올린 판매 등록 1건 | |
| 즉시구매가 (Buyout) | 매물을 바로 살 수 있는 가격 | |
| 에스크로 (Escrow) | 등록한 아이템을 판매자 인벤토리에서 빼서 보관하는 상태 | 판매되면 구매자에게, 만료되면 판매자에게 |
| 수수료 | 판매 체결 시 판매 대금에서 떼는 코인. 재화를 회수하는 장치 | |
| 시세 | 아이템별 최근 체결가·최저 매물가 | |
| 찜 (Favorite) | 관심 매물 저장 | |
| 진화 (Evolution) | M2. 열매를 써서 펫을 같은 계열의 다음 단계 종으로 바꾸는 것. 진화형을 얻는 유일한 방법 | 02_게임_시스템_규칙 §8 |
| 열매 (Fruit) | M2. 진화 재료 아이템 (`FRUIT`). 새싹·반짝·별 3종 | 02_게임_시스템_규칙 §8-2 |

## D. 보안 / JWT
| 용어 | 한 줄 정의 | 예시 / 관련 문서 |
|---|---|---|
| Access Token | API 호출용 짧은 수명 JWT (현재 30분, HS256) | `auth/SecurityConfig` |
| Refresh Token | Access 재발급용 토큰 (미구현, API 단계에서 결정) | |
| 서버 권위 (Server Authoritative) | 결과를 서버가 결정하고 클라이언트 입력을 믿지 않는 원칙 | 뽑기·미니게임 |
| 서명 URL | 짧은 시간만 유효한 서명된 에셋 주소 | 로드맵 2 AI 펫 |
