# 01. 기능 카탈로그 · MoSCoW · 마일스톤 컷

> ⚠️ 2026-11-16 초안. 본 박스가 최신이며, 본문과 충돌하면 박스를 우선한다.
> "관련 API" 칸은 **잠정 경로**다. 확정은 `04_api/02_엔드포인트_목록.md`에서 하고, 확정되면 이 칸을 갱신한다.
> 경로 접두사는 현재 코드에 맞춰 `/api/v1`을 쓴다(결정 D-1, `04_api/README.md`).

## 우선순위 기준
| 등급 | 의미 | 본 프로젝트 의미 |
|---|---|---|
| MUST | 없으면 서비스가 성립하지 않음 | M1 |
| SHOULD | 핵심 경험을 완성함 | M2 |
| COULD | 여유가 있으면 | M3 또는 여유 |
| WON'T | 이번 범위 아님 | v1.1 이후 |

## 핵심 루프
```
 [출석·미니게임] ──코인──▶ [뽑기] ──펫──▶ [마이 홈: 장착·상호작용]
        ▲                                  │
        │                                  ▼ 남는 의상·가구
   [경매장 판매 대금] ◀──────────────── [경매장 등록]
        │
        └──코인──▶ [상점·경매장 구매] ──아이템──▶ [마이 홈 꾸미기]
```

## 도메인별 기능 표

### M. member (회원) — 일부 구현됨
| ID | 기능 | 등급 | 마일스톤 | 관련 API (잠정) | 인수 기준(AC) |
|---|---|---|---|---|---|
| M-01 | 회원가입 | MUST | M1 | POST /api/v1/auth/register | 이메일·닉네임 중복 시 409. 가입 시 지갑(0코인)과 기본 마이 홈 생성, **가입 선물 코인 지급** |
| M-02 | 로그인 | MUST | M1 | POST /api/v1/auth/login | 이메일/비밀번호 구분 없는 실패 메시지 (구현됨) |
| M-03 | 내 정보 조회·닉네임 변경 | MUST | M1 | GET·PATCH /api/v1/members/me | 구현됨. 응답에 코인 잔액·대표 펫 요약 추가 |
| M-04 | 토큰 재발급 (Refresh) | SHOULD | M2 | POST /api/v1/auth/refresh | Access 만료 시 재로그인 없이 재발급 |
| M-05 | 로그아웃 | SHOULD | M2 | POST /api/v1/auth/logout | Refresh 무효화 |
| M-06 | 소셜 로그인 (Google/Naver) | COULD | M3 | /oauth2/authorization/{provider} | 참조 원본 04 OAuth 구성 |
| M-07 | 회원 탈퇴 | COULD | M3 | DELETE /api/v1/members/me | 소프트 딜리트. 진행 중 매물은 자동 취소 |

### P. pet (펫)
| ID | 기능 | 등급 | 마일스톤 | 관련 API (잠정) | 인수 기준(AC) |
|---|---|---|---|---|---|
| P-01 | 내 펫 목록 | MUST | M1 | GET /api/v1/pets | 종·이름·희귀도·기분·친밀도 단계·장착 요약. 종당 1마리 |
| P-02 | 펫 상세 | MUST | M1 | GET /api/v1/pets/{petId} | 본인 펫만 조회 (타인은 403 또는 404) |
| P-03 | 펫 이름 짓기 | MUST | M1 | PATCH /api/v1/pets/{petId} | 1~12자, 금칙어 검사(간이) |
| P-04 | 대표 펫 지정 | MUST | M1 | PATCH /api/v1/pets/{petId}/representative | 항상 대표 펫은 1마리 (첫 펫은 자동 대표) |
| P-05 | 상호작용 (쓰다듬기·놀아주기·간식) | MUST | M1 | POST /api/v1/pets/{petId}/interactions | 종류별 쿨다운. 기분·친밀도 상승. 응답에 재생할 움직임 키 포함 |
| P-06 | 친밀도 단계 해금 | MUST | M1 | (P-05 부수효과) | 단계 상승 시 해당 종의 해금 움직임이 인벤토리에 지급됨 |
| P-07 | 도감 | SHOULD | M2 | GET /api/v1/pets/collection | 전체 종 목록 + 보유 여부. 미보유는 실루엣 |
| P-08 | 펫 놓아주기 | COULD | M3 | DELETE /api/v1/pets/{petId} | 대표 펫·마지막 1마리는 불가. 장착 아이템은 인벤토리로 반환 |

### G. gacha (뽑기)
