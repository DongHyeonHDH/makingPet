# 02. 엔드포인트 목록 (SSoT)

> ⚠️ 2026-11-16 확정 초안. **여기 없는 엔드포인트는 만들지 않는다.** 추가가 필요하면 이 문서부터 갱신한다.
> 범례: 🔓 익명 · ✅ USER · 🛡 ADMIN · 👑 SUPER_ADMIN · 🔑 `Idempotency-Key` 필수
> 마일스톤: 표시 없음 = M1, (M2), (M3)

## 0. 최근 결정 사항
- 응답은 전부 `ApiResponse<T>` 래퍼. 성공 `data`, 실패 `error.code`.
- 중복 펫은 코인 환급. `user_pets (member_id, species_id)` 유니크.
- 매물 상태: `ON_SALE → SOLD | CANCELLED | EXPIRED | REMOVED`
- 쿨다운·일일 한도 초과는 429 + `Retry-After`.
- 실시간 채널은 M3에 SSE 1개(`/api/v1/notifications/stream`). 프로토콜 명세서는 별도 문서.
