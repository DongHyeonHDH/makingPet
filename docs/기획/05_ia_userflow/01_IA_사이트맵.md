# 01. IA · 사이트맵

> ⚠️ 2026-11-16 초안. 화면 구성은 `web-preview/index.html` 시안을 기준으로 한다.

## 화면 트리
```
/                         랜딩 (비로그인) → 로그인/가입
/login  /signup
/home                     ★ 내 방 (마이 홈) — 로그인 후 첫 화면
 ├─ 펫 상호작용 (쓰다듬기·놀아주기·간식)
 ├─ 꾸미기 패널: 펫 장착 (상의·하의·악세서리·움직임)
 └─ 방 꾸미기 패널: 테마·가구
/pets                     내 펫 목록 → /pets/{id} 상세 (이름·대표 지정)
/collection               도감
/gacha                    새 친구 만나기 (뽑기, 확률표, 기록)
/rewards                  오늘의 보상 (출석 달력 · 가위바위보 · 빠칭코)
/shop                     상점
/auction                  경매장
 ├─ 검색 (필터: 이름·종류·최대가, 정렬: 가격·마감)
 ├─ 시세
 ├─ 찜
 ├─ 판매 (등록 폼 + 내 판매 중)
 └─ 완료 (거래 내역)
/homes/{nickname}         다른 유저의 마이 홈 (개인 페이지, 읽기 전용)
/notices  /notices/{id}   공지사항
/me                       내 정보 · 코인 내역
/admin/**                 운영 (카탈로그·뽑기 풀·공지·재화 보정)
```
상단 고정 영역: 코인 잔액, 오늘 남은 보상 배지, 메뉴.

## 화면 ↔ API (잠정)
| 화면 | 경로 | 권한 | 호출 API |
|---|---|---|---|
| 로그인/가입 | /login, /signup | 익명 | M-01, M-02 |
| 내 방 | /home | USER | H-01, P-05, H-02, H-03, H-04, W-01, R-05 |
| 내 펫 | /pets | USER | P-01~P-04, P-08 |
| 도감 | /collection | USER | P-07 |
| 뽑기 | /gacha | USER | G-01~G-06 |
| 오늘의 보상 | /rewards | USER | R-01~R-05 |
| 상점 | /shop | 익명 조회 / USER 구매 | S-01, S-02 |
| 경매장 | /auction | 익명 조회 / USER 거래 | A-01~A-09 |
| 다른 유저 마이 홈 | /homes/{nickname} | 익명 또는 USER (결정 필요) | H-05 |
| 공지 | /notices | 익명 | C-01 |
| 내 정보 | /me | USER | M-03, W-02 |
| 운영 | /admin | ADMIN | AD-01~AD-05 |
