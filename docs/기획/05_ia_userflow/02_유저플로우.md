# 02. 유저플로우

> ⚠️ 2026-11-16 초안. 괄호 안은 기능 ID(`06_features/01_기능_카탈로그.md`).

## 플로우 1. 신규 유저 → 첫 펫과 놀기
1. 가입 (M-01) → 지갑 생성, **가입 선물 300 코인**, 기본 테마 지급, 빈 마이 홈 생성
2. 로그인 (M-02) → 펫이 없으면 `/gacha`로 안내
3. 뽑기 풀·확률 확인 (G-01) → 1회 뽑기 (G-02) → 첫 펫은 자동 대표 펫
4. 이름 짓기 (P-03)
5. `/home`에서 쓰다듬기 (P-05) → 움직임 재생, 기분·친밀도 상승
6. 오늘의 보상으로 출석 (R-01) 안내

## 플로우 2. 매일 접속하는 유저 → 코인 모으기
1. `/home` 진입 (H-01, R-05) → 남은 보상 배지 확인
2. 출석 (R-01) → 가위바위보 (R-03) → 빠칭코 최대 5회 (R-04)
3. 모은 코인으로 뽑기 (G-02) 또는 상점 구매 (S-02)

## 플로우 3. 꾸미기 유저 → 펫과 방 꾸미기
1. 상점에서 의상 구매 (S-02) → 인벤토리 (I-01)
2. `/home` 꾸미기 패널에서 상의·악세서리 장착 (H-02) → 해당 수량 `reserved` 증가
3. 친밀도 단계 상승으로 받은 움직임을 MOTION 슬롯에 장착 (P-06, H-02)
4. 테마 변경 (H-03), 가구 배치 (H-04)
5. 공개 설정 (H-06) → 다른 유저가 `/homes/{nickname}`으로 방문 (H-05)

## 플로우 4. 판매자 → 경매장에 의상 팔기
1. `/auction` 판매 탭 → 거래 가능 수량이 있는 아이템만 선택지에 나옴 (I-01)
2. 가격·기간 입력 후 등록 (A-03) → 인벤토리 수량 1 감소(에스크로)
3. 내 판매 목록에서 상태 확인 (A-07)
4. (a) 팔림 → 판매가 − 5% 수수료 입금, 완료 탭에 기록
   (b) 취소 (A-05) → 아이템 반환
   (c) 만료 (A-06) → 아이템 자동 반환

## 플로우 5. 구매자 → 경매장에서 사기
1. 검색 (A-01): 이름·종류·최대가 필터, 가격 정렬
2. 시세 확인 (A-09) → 매물 선택 (A-02) → 찜 (A-08) 또는 구매 (A-04)
3. 구매 성공 → 인벤토리에 추가, 코인 차감 / 동시에 다른 사람이 먼저 샀으면 "이미 판매된 매물" 안내 후 목록 새로고침

## 플로우 6. 운영자 → 새 펫 출시
1. 펫 종 등록 (AD-01) → 해금 움직임 아이템 등록·연결
2. 기간 한정 뽑기 풀 생성, 확률표 입력(합계 검증) (AD-02)
3. 공지 작성 (AD-03)
