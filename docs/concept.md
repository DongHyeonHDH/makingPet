# 기본적인 콘셉트
펫 뽑기를 통해 펫을 얻고 펫에 움직임과 같은 상호작용을 통해 움직임을 더할 수가 있다.
펫은 움직임, 상의, 하의, 악세서리 등과 같은 것을 마이 홈이라는 공간으로 가서 꾸미는 것이 가능하다.

# 육성, 성장 시스템
이거는 MVP는 아니고 추후 시스템으로 특정 장비나 열매를 먹이면 5가지 이상의 진화과정을 거치게 된다.
이거는 출석이나 가위바위보, 빠칭코와 같은 시스템으로 뽑을 수 있게 할 것이다.

# 캐릭터 아트
고라파덕, 모찌, 치이카와와 같이 조금은 허술한 귀여운 매력이 있는 애들을 캐릭터로 삼고 싶다.

# 아이템 재화 
재화는 유료는 없고 출석, 1일 1회 가위바위보, 빠칭코와 같은 시스템으로 얻을 수 있게 할 것이다.

2. 그렇게 자신이 키운 펫을 AI 펫처럼 부가능을 제공하는 프로그램으로 도입하고 보여질 수 있도록 한다.
