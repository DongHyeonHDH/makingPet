## 결정 사항
- **판매 중** = 상품 `visible` · 기간 안(KST, 끝 시각 포함) · 아이템 `active`. 판매 중이 아니면 S-2는 404, S-3은 409.
- S-3은 한 트랜잭션: 판매 확인 → `wallet.debit`(조건부 UPDATE) → `inventory.grant`(행 잠금) → `shop_purchases` 기록. 원장 `ref_type=SHOP_PURCHASE`, `ref_id=purchaseId`.
- 멱등 해시 대상은 `record(productId, quantity)`. `Map.of`는 순회 순서가 JVM마다 달라 재기동 후 같은 요청이 `IDEMPOTENCY_KEY_REUSED`가 될 수 있다. (G-2 뽑기가 `Map.of`를 쓰고 있어 같은 위험이 있음 → 후속 수정 후보)
- 관리자 API의 시각 입력은 `OffsetDateTime`으로 받아 KST `LocalDateTime`으로 바꿔 저장한다.
- PATCH에서 변경 불가 필드(code·rarity·category)가 오면 조용히 무시하지 않고 400 `VALIDATION_FAILED`.
- PATCH의 `null`은 "보내지 않음". 판매 기간을 다시 무기한으로 되돌리는 방법은 아직 없다(필요하면 명시적 clear 필드 추가).
- **관리자 계정 시드**: `MAKINGPET_ADMIN_PASSWORD`가 있을 때만 SUPER_ADMIN 계정(기본 `admin@makingpet.local` / `운영자`)을 만든다. 비밀번호를 저장소에 두지 않기 위함. 금칙어 검사(“운영자”)는 시드 경로에서만 건너뛴다.

## 로컬에서 관리자 쓰기
```
MAKINGPET_ADMIN_PASSWORD=원하는비밀번호 ./gradlew bootRun
POST /api/v1/auth/login { "email": "admin@makingpet.local", "password": "..." }
```
