### 지금 yaml 의 안전 장치 (중단하면서 되돌려 둠)
```
11:      ddl-auto: ${DDL_AUTO:update}      # TODO V1__init.sql 작성 후 validate 로 전환
19:    enabled: ${FLYWAY_ENABLED:false}   # TODO V1__init.sql 작성 후 true
21:    # ddl-auto=update 로 이미 만들어진 DB 에 처음 붙일 때만 true (기존 스키마를 V1 로 간주하고 V2 부터 적용).
```
- Flyway 마이그레이션 SQL 이 아직 없어서 **`ddl-auto=update`, `FLYWAY_ENABLED=false`** 로 두었다. V1 작성 후 `validate` / `true` 로 바꾼다.
- `spring.cache.type` 기본값은 `none` (Redis 없이 기동). 운영은 `CACHE_TYPE=redis`.
- `hibernate.type.prefer_native_enum_types=false` 를 넣었다(H2·PostgreSQL enum 을 varchar 로 통일하려는 의도). **이 설정 키가 Hibernate 7.4 에서 유효한지 미확인.**
