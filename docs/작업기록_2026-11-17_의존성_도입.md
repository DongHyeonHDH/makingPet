## 4. 알아둘 점
- **H2 와 PostgreSQL 의 enum 컬럼**: Hibernate 는 H2 에서 enum 을 `ENUM(...)` 타입으로 기대하지만, V1 은 `varchar + check` 로 만든다. H2 에서도 validate 가 통과하고 값 저장도 정상임을 테스트로 확인했다. 그래서 마이그레이션은 한 벌로 유지한다. (`prefer_native_enum_types` 설정은 H2 에 효과가 없어 넣지 않았다.)
- **기존 PostgreSQL DB** 를 `ddl-auto=update` 로 이미 만들어 둔 경우, 처음 한 번은 `FLYWAY_BASELINE_ON_MIGRATE=true` 로 띄운다 (기존 스키마를 V1 로 간주). 새 DB 는 그대로 띄우면 된다.
- **캐시 무효화는 비동기**: Spring Data Redis 4 는 캐시 비우기를 별도 연결에서 처리해 커밋 직후 수 ms 안에 반영된다. 운영 영향은 없고, 테스트는 잠깐 기다리며 확인한다.
- **엔티티를 바꾸면** `V2__설명.sql` 을 추가해야 한다. 안 하면 기동 시 validate 가 실패한다 (의도된 안전장치).
